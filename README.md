# Loni Unser Racing

Static landing page (no build step). Open `index.html` or run `python3 -m http.server`.

- **Content**: replace `[bracketed]` placeholders in `index.html`.
- **Schedule / countdown**: edit `RACES` at top of `script.js`.
- **Photos**: put files in `assets/`; set hero via `.hero-bg`, portrait via `.photo`, gallery via `.g1`–`.g5` in `styles.css`.
- **Merch**: waitlist form is a stub in `script.js`. When ready, link products to Shopify (Buy Button / Storefront) or a hosted store.
